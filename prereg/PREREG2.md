# 사전등록 2 — 감쇠 상수 c 의 결정요인 (1분 해상도, 과거 사다리 포함)

**PREREG.md (sha256:12a0a16ad7f1931b) 의 후속.** 대체가 아니라 추가다. 1차 결과는 그대로 보고한다.

## 1차가 실패한 이유 (기록)
- 샘플링 60분 고정 → 1시간짜리 KXGOLDH 가 봉 1~2개로 전멸
- 열린 마켓만 조회 → 이벤트가 시리즈당 1개뿐, 유효표본 40 미달
- 결과: 5개 사다리 전부 적합 실패. 판정 불가.
- **판정 규칙이 KXGOLDH 존재를 전제했는데 그 점이 빠지면서 규칙 자체가 무력화됨**

## 이번에 바꾸는 것 (셋뿐, 그 외 동일)
1. 캔들 해상도 60분 → **1분** (period_interval=1). 비중첩 리샘플은 유지
2. `status=open` → **`status=settled` 포함**. 과거 사다리를 이벤트 단위로 풀링
3. 조회 창을 계약 수명(open_time~close_time)으로 한정. 72시간 초과 시 분할

## 이미 본 데이터 (편향 원천 명시)
- KXGOLDW 60분 곡선: c=6.51h, A=1.53
- 1차 실행의 원시 정체율: GOLDD 6%, GOLDW 46%, BTCD 15%, GOLDH 측정불가
- 위 두 가지가 이 문서 작성에 영향을 주었다.
- **1분 해상도의 rho2 곡선은 어느 사다리에서도 아직 보지 않았다.** 이번이 첫 관측이다.

## 대상 (사전 확정, 이후 추가·제외 금지)
KXGOLDH, KXGOLDD, KXGOLDW, KXBTCD, KXETHD
각 시리즈에서 settled 이벤트를 최근순으로 최대 20개.

## 모형
rho2_obs(h) = A/(1 + c/h),  A <= 1 제약.  이벤트별 rho2 의 중앙값으로 곡선을 만들고
시리즈당 c 하나를 적합한다.

## 지평 (사전 확정)
5, 15, 30, 60, 120, 240, 480 분.  비중첩.
계약 수명이 짧아 특정 지평에서 표본이 안 나오면 그 점만 결측 처리한다.

## 최소 표본 (사전 확정)
지평별 유효표본 n(1-정체율) >= 30.  (1차의 40 에서 완화 — 1분 계약을 살리기 위함이며
이 완화가 결과에 유리하게 작용할 수 있음을 명시한다.)
곡선 점이 3개 미만이면 그 시리즈는 **적합 실패로 보고**한다. 제외하지 않는다.

## 경쟁 가설
### H1 이산성 지배 :  c ∝ (Δ/S)² / σ²
  금 3종은 σ 동일. 예측 비율
    c(GOLDD)/c(GOLDH) = (0.230/0.045)² = 26.1
    c(GOLDW)/c(GOLDH) = (0.460/0.045)² = 104.5
    c(GOLDW)/c(GOLDD) = (0.460/0.230)² = 4.0
### H2 비동기(정체) 지배 : c 는 격자와 무관, 정체율에 비례
  예측: 위 세 비율이 모두 [0.5, 2] 이고, c 와 원시정체율의 순위상관 > 0.7
### H3 혼합 : 두 항 모두 기여

## 판정 규칙 (사전 확정)
주 판정은 **c(GOLDW)/c(GOLDH)** 로 한다.
  [50, 200]  → H1 지지
  [0.5, 2]   → H2 지지
  (2, 50)    → H3. 단 로그 c 를 log(Δ/S)² 와 정체율에 회귀했을 때 두 계수 모두 부호가
               예측대로여야 한다. 아니면 "설명 실패".
  그 외      → 설명 실패
GOLDH 가 또 실패하면 주 판정 불가로 보고하고, 보조로 c(GOLDW)/c(GOLDD) [예측 4.0] 만 제시한다.

## 절차 고정
- 가격은 호가 중간값만. 체결가 폴백 금지
- 정체율은 rho2 와 독립적으로 원시 1분 호가 계열에서 측정
- BTC/ETH 는 σ 가 달라 금 내부 비교의 보조 증거로만 쓴다. 주 판정에 넣지 않는다
- 실행은 1회. 파라미터를 바꿔 재실행하지 않는다. 바꾸려면 새 사전등록을 쓴다
