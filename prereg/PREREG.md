# 사전등록 — 감쇠 상수 c 의 결정요인

작성 시각: (아래 타임스탬프 참조).  **적합 결과를 보기 전에 작성됨.**

## 모형
rho2_obs(h) = A / (1 + c/h),  단 A <= 1 제약.
c 는 절반 감쇠 지평. 자산·계약별로 하나씩 적합한다.

## 대상 (사전 확정, 이후 추가·제외 금지)
KXGOLDH, KXGOLDD, KXGOLDW, KXBTCD, KXETHD

## 관측된 계약 명세 (적합과 무관, 이미 측정됨)
       격자 Δ/S      기초자산 σ(1h)
GOLDH   0.045%        0.288%
GOLDD   0.230%        0.288%
GOLDW   0.460%        0.288%
BTCD    0.157%        0.439%
ETHD    0.265%        0.583%

## 경쟁 가설과 각각의 정량 예측

### H1 — 이산성 지배
c ∝ (Δ/S)² / σ².  격자가 잡음의 주된 원천.
금 3종은 σ 가 같으므로 c 비율이 격자 제곱비와 같아야 한다.
  예측: c(GOLDD)/c(GOLDH) = (0.230/0.045)² = 26.1
        c(GOLDW)/c(GOLDH) = (0.460/0.045)² = 104.5
        c(GOLDW)/c(GOLDD) = (0.460/0.230)² = 4.0

### H2 — 비동기(정체) 지배
c 는 격자와 무관하고 정체율에 비례한다.
  예측: 금 3종의 정체율이 비슷하면 c 도 비슷하다 (비율 ≈ 1, 허용 2배 이내).
        c 와 정체율의 순위상관 > 0.7.

### H3 — 혼합
c = a·(Δ/S)²/σ² + b·(정체율 항).  a, b 모두 유의.

## 판정 규칙 (사전 확정)
- c(GOLDW)/c(GOLDH) 가 [50, 200] 이면 H1 지지
- 같은 비율이 [0.5, 2] 이면 H2 지지
- 그 사이(2~50)면 H3, 단 두 항 모두 유의해야 한다
- 어느 쪽도 아니면 "설명 실패" 로 보고한다

## 사전 확정된 절차
- 지평 격자: 1, 2, 4, 8, 12, 24, 48 시간 (비중첩)
- 가격: 호가 중간값. 체결가 폴백 금지
- 정체율은 rho2 적합과 독립적으로 원시 호가 계열에서 측정
- 유효표본 n(1-정체율) < 40 인 지평 점은 제외
- 적합 실패(A>1 또는 수렴 불가)한 사다리는 제외하지 않고 실패로 보고

## 이미 알고 있는 것 (편향 원천으로 명시)
KXGOLDW 를 앞서 5개 점으로 적합한 결과 c=6.51h, A=1.53(제약 위반) 이 나왔다.
틱·스프레드 기반 예측(0.018~0.281h)과 23~370배 차이가 났다.
이 사실이 위 가설 설정에 영향을 주었음을 명시한다. GOLDW 는 이미 본 데이터다.
**GOLDH, GOLDD, BTCD, ETHD 는 아직 보지 않았다.** 이 넷이 사실상의 검증 표본이다.
