# hs-collect v3 배포 (맥미니)

## 무엇이 바뀌었나

### 크리티컬 — 폴리마켓 US 정치·문화 수집 시작
폴리마켓 US 는 가격이력 API 가 **없다**(history/candlesticks/prices-history 전부 404).
지금 안 받으면 영구 소실이다. 반면 칼시는 캔들 API 로 **1분봉 사후 백필이 된다**
(48시간 전 구간 244개 반환 실측). 이 비대칭이 이번 패치의 근거다.

- 이전: `SKIP=("sports","politics","culture")` → 비스포츠 OPEN 5,382 중 **4,968개를 버림**
  (그중 1,651개가 실제 거래 중). 이들은 전통 쌍둥이가 없는 가장 깊은 마켓이고
  (Maine Senate $117k > CPI $73k), 논문 틀 C(유일성 프리미엄)의 핵심 증거다.
- 이후: `pmus_lite` 티어 신설. 정치·문화를 **bbo 만, 10분 간격**으로 추적.
  호가 깊이는 안 받는다 — 가격 시계열만 있으면 틀 C 는 성립한다.

### 성능 — lite 스캔을 메인 루프에서 분리
2,500건을 메인 루프에서 돌리자 호가창 사이클이 60초 → 200초로 늘어났다(실측).
크리티컬 스트림을 느리게 만들면 본말전도라 **전용 스레드 + 전용 풀(8워커)** 로 뺐다.
검증: 분리 전 220초에 1사이클 → 분리 후 2사이클로 회복.

### 칼시 — 근일 계약만 추적
KXBTCD/KXETHD 는 시간당 ~160 행사가 × 24시간이라 핀 용량을 통째로 먹었고,
그 결과 살아있는 계약이 97~104분에 1회로 굶었다(KXBTC15M 은 470분).
`near_dated()` 로 마감 8시간 이내만 남긴다 → 추적 688 → 361, 밀도 상승.
칼시는 사후 백필되므로 라이브는 근일에 집중하는 편이 낫다.
(주의: 캔들은 최우선 호가만 준다. **깊이는 백필 불가** — 근일 깊이가 필요하면 라이브가 유일)

## 새 환경변수

| 변수 | 기본값 | 뜻 |
|---|---|---|
| `HS_LITE_CAP` | 2500 | 정치·문화 추적 상한 |
| `HS_LITE_EVERY` | 600 | lite bbo 주기(초) |
| `HS_LITE_WORKERS` | 8 | lite 전용 스레드풀 |
| `HS_KALSHI_NEAR_H` | 8 | 칼시 근일 창(시간) |

## 배포

```bash
cp collect.py ~/hs-collect/collect.py
launchctl kickstart -k gui/$(id -u)/com.hscollect
```

되돌리려면 `collect.py.v2.bak` 을 복사하면 된다.

## 배포 후 확인 (5분 뒤)

```bash
python3 ~/hs-collect/collect.py --status
```
`pinned` 에 `pmus_lite` 가 2,000 이상, `kalshi` 가 300~450 이면 정상.
health 스트림에 `lite_scan` 레코드(secs, n)가 10분마다 남는다.

## 용량 영향
- lite 추가: +26MB/일 (2,500건 × 6회/시 × 72B)
- 칼시 축소: −12MB/일
- 순증 ≈ +14MB/일 → **약 134MB/일**
